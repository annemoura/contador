# 🔢 Contador

Projeto desenvolvido para praticar conceitos básicos de desenvolvimento web utilizando **HTML, CSS e JavaScript**.

A aplicação permite aumentar, diminuir e resetar o valor do contador, além de trabalhar com limites definidos e alterações visuais conforme o valor exibido.

## ✨ Funcionalidades

- ➕ Incrementar o contador
- ➖ Decrementar o contador
- 🔄 Resetar o contador para zero
- ⬆️ Limite máximo de `10`
- ⬇️ Limite mínimo de `-10`
- 💬 Exibição de mensagens quando os limites são atingidos
- 🎨 Alteração visual de acordo com o valor do contador

## 🛠️ Tecnologias utilizadas

- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript

## 🎯 Objetivo do projeto

Este projeto foi criado com o objetivo de praticar:

- 🧠 Lógica de programação
- 🖱️ Eventos de clique
- 🔀 Estruturas condicionais
- 🧩 Manipulação do DOM
- 🎨 Alteração de estilos utilizando JavaScript
- 📄 Integração entre HTML, CSS e JavaScript
